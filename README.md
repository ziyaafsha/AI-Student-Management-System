
# AI Student Management System

## Project Description
The AI Student Management System is a web-based
application developed to manage student records
efficiently and digitally.

## Objectives
- Manage student information
- Provide secure admin login
- Register new students
- Search student records
- Update and delete student information
- Display student statistics

## Technologies Used
- HTML
- CSS
- JavaScript
- Python Flask
- SQLite
- GitHub

## Development Methodology
Agile methodology with iterative development,
task assignment and continuous collaboration.

## Main Modules
1. Admin Login
2. Dashboard
3. Student Registration
4. Student Database
5. Search and Filter
6. Edit and Delete

## Installation
1. Clone the repository.
2. Install Python.
3. Install Flask using pip.
4. Run app.py.
5. Open http://127.0.0.1:5000.
